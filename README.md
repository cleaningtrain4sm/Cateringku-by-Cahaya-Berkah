# Cateringku by Cahaya Berkah — PWA Wrapper

Halaman pembungkus (wrapper) untuk aplikasi Google Apps Script Cateringku agar bisa di-install sebagai PWA di HP.

Aplikasi utama dimuat di dalam iframe dari URL deployment Apps Script. Situs ini menyediakan manifest, ikon, dan service worker agar Chrome/Android menganggapnya aplikasi yang dapat di-install.
